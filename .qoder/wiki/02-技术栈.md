补充说明：

- **包管理器统一 yarn（1.22.x）**，禁用 npm（避免 `package-lock.json` 与 `yarn.lock` 双锁文件冲突；`.gitignore` 已忽略 package-lock.json）
- **dayjs** 被 `TimestampToolView.vue` 直接 import，但它不在 package.json 直接依赖中，是 ant-design-vue 的传递依赖（node_modules 扁平化故可用）；如需长期依赖建议显式 `yarn add dayjs`
- 没有 test、lint 或独立 typecheck 脚本；`yarn build`（vue-tsc + vite build）是唯一类型检查入口
- `start` 脚本存在 `yarn rnu dev` 拼写错误，请使用 `yarn dev`
- Vite 仅配置 Vue 插件与 `@ → src` alias，无 dev proxy；history 路由部署需 SPA fallback

## 基础设施与外部服务

| 组件 | 说明 |
|---|---|
| PostgreSQL | 18.x，`zytool` 库；Rust 主用，Python 仅供 admin；DDL 源文件 `ToolsAI/zytool.sql`（需手工执行，Rust 不做 migration） |

| 和风天气 | `QWEATHER_API_KEY` + `QWEATHER_HOST`（新控制台账号必须配专属 API Host，否则 403 Invalid Host）；GeoAPI 路径为 `{host}/geo/v2/city/lookup`（旧 `geoapi.qweather.com/v2` 已下线） |

| QQ 互联 | OAuth 登录（`QQ_APP_ID / QQ_APP_KEY / QQ_REDIRECT_URI`），授权回调在前端 `/` 完成 |
